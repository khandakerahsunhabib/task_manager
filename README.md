<h2>📱 Task Manager App Overview</h2>
<p>A modern, minimal task management application built using Flutter and GetX, designed for seamless productivity and user-friendly interaction.</p>

<h3>🛠 Tech Stack</h3>
<ul>
    <li><strong>Flutter - </strong>Cross-platform UI framework</li>
    <li><strong>Dart - </strong>Programming language</li>
    <li><strong>GetX - </strong>State management and navigation</li>
    <li><strong>Responsive UI - </strong>Optimized for mobile screens</li>
</ul>
<h3>🔐 User Authentication</h3>
<ul>
    <li>Email-based sign-up and login</li>
    <li>PIN verification for email confirmation</li>
    <li>Password setup and reset functionality</li>
    <li>Secure user authentication flow</li>
</ul>
<h3>✅ Core Features</h3>
<ul>
    <li><strong>Task Dashboard: </strong>View all tasks organized by status and date.</li>
    <li><strong>Add New Task: </strong>Enter a task title and description with a simple form.</li>
    <li><strong>Bottom Navigation Bar: </strong>Navigate easily between Home, Add Task, and Profile.</li>
    <li><strong>Task Categorization: </strong>Color tags indicate task categories or priorities.</li>
    <li><strong>Profile Management: </strong>Update name, phone, and password directly from the profile screen.</li>
</ul>
<h3>🎨 Design & UI</h3>
<ul>
    <li>Clean and consistent design</li>
    <li>Minimalist color palette</li>
    <li>Simple, intuitive form layout</li>
    <li>Clear visual hierarchy for ease of use</li>
</ul>
